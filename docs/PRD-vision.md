# 확장 방향 정의서 (초안)

작성일: 2026-10-13
관계: [요구사항 정의서](PRD.md)는 지금 만든 버전(개인용, 로그인 없음)을 다룹니다. 이 문서는 그 다음에 가고 싶은 방향을 적은 초안이며, 수요를 확인한 결과는 아직 없습니다.

---

## 1. 한 줄 방향

> 혼자 쓰면서 쌓은 **고친 기록이 붙은 규칙**을 다른 사람과 나누고, 나중에는 사고팔 수 있게 합니다.

지금 버전이 증명하려는 것은 "내 작업에서 고치는 일이 줄었는지"입니다. 확장 방향은 이 기록을 다른 사람에게도 보이게 해서, 규칙을 고를 때 근거로 쓰게 하는 것입니다.

---

## 2. 단계

| 단계 | 내용 | 요금 | 필요한 것 |
| --- | --- | --- | --- |
| 1. 지금 | 나만의 규칙 만들기, 고침/안 고침 기록, 맡겨볼 만한 때 알림 | 무료 | 지금 버전 (브라우저 저장) |
| 2. 보관 | 내 업무 양식과 규칙을 계정에 보관하고 다른 기기에서 이어 쓰기 | 무료 | 로그인, 서버 저장 |
| 3. 공유 | 규칙을 기록과 함께 공개하고, 쓴 사람들이 인사이트를 나누는 커뮤니티 | 무료 | 공개 범위 설정, 민감한 정보 걸러내기 |
| 4. 거래 | 기록이 쌓인 규칙을 사고파는 마켓 | 거래 수수료 | 결제, 판매자 정책, 환불 기준 |
| 5. 자동화 | 맡겨볼 만한 규칙을 다른 AI 예약 작업이나 자동화 도구에 연결 | 미정 | 외부 도구 연동 |

나만의 규칙을 세우는 일은 끝까지 무료로 둡니다. 기록이 쌓여야 공유와 거래의 근거가 생기기 때문입니다.

## 3. 이미 있는 것과 다른 점

규칙(프롬프트)을 나누거나 파는 기능 자체는 이미 있습니다.

| 서비스 | 하는 일 | 믿게 만드는 방식 |
| --- | --- | --- |
| PromptBase | 프롬프트·스킬 판매 마켓. 약 33만 개 등록, 마켓 판매 시 수수료 20% | 등록 전 심사, 별점, 구매자 후기 |
| GPT 스토어 | 직접 만든 GPT 공개. 수익 배분은 미국 일부 제작자 시범에 그쳤고, 개인 계정의 새 GPT 공개는 막혔으며 GPT 자체를 정리하는 중 | 사용량, 평점 |
| 노션 템플릿 등 | 업무 양식 공유·판매 | 다운로드 수, 후기 |

다른 점은 **믿게 만드는 방식**입니다. 위 서비스들은 별점, 후기, 사용량에 기대고, 실제로 써 봤을 때 고칠 게 줄었는지는 기록하지 않습니다. 또시켰네의 규칙에는 "몇 번 써서 몇 번 연속 안 고쳤는지"가 같이 붙습니다.

이 비교는 2026-10-13에 찾아본 범위입니다. 기록이 붙은 규칙을 거래하는 서비스가 정말 없는지는 더 확인해야 합니다.

## 4. 미리 생각해 둘 위험

1. **남의 기록이 내 결과를 보장하지 않습니다.** 그 사람의 자료에서 안 고쳤다는 뜻이지, 내 자료에서도 그렇다는 뜻은 아닙니다. 판매 화면이 "검증된 규칙"처럼 보이면, 지금 버전에서 피해 온 정확도 보장 오해가 돈이 걸린 채로 다시 생깁니다. 기록은 "이 사람이 이렇게 썼다"로만 보여 줘야 합니다.
2. **규칙은 글이라 쉽게 복사됩니다.** 사고팔 가치가 규칙 글 자체보다 기록, 업데이트, 판매자의 관리에서 나와야 합니다.
3. **공유하는 순간 민감한 정보 문제가 커집니다.** 규칙에 사람 이름, 회사 숫자, 고객 정보가 섞일 수 있어 공개 전에 걸러내는 장치가 필요합니다.
4. **기록을 부풀릴 수 있습니다.** 판매자가 쉬운 자료로 안 고침 횟수를 쌓을 수 있습니다. 구매자가 직접 쓴 기록을 따로 보여 주는 방식을 검토해야 합니다.
5. **마켓 수익은 약속대로 안 될 수 있습니다.** GPT 스토어도 수익 배분을 발표했지만 넓게 열지 못했습니다. 거래 단계 전에 공유 단계에서 실제로 규칙을 찾아 쓰는 사람이 있는지 먼저 봐야 합니다.

## 5. 확인할 것

| 질문 | 확인 방법 |
| --- | --- |
| 남이 만든 규칙을 가져다 쓸 생각이 있는가 | 10/16 박람회에서 질문하거나, "다른 사람 규칙 보기" 버튼을 두고 눌러 보는지 확인 |
| 기록이 붙어 있으면 더 믿고 고르는가 | 기록이 있는 규칙과 없는 규칙을 나란히 보여 주고 고르게 하기 |
| 돈을 내고 살 만한 규칙이 있는가 | 공유 단계에서 많이 가져다 쓰인 규칙과 그 이유 보기 |
| 내 규칙을 공개할 생각이 있는가 | 공개 범위를 고르게 했을 때 실제로 공개하는 비율 |

지금은 이 질문들에 대한 데이터가 없습니다. 단계 2 이후는 위 확인 결과를 보고 정합니다.
