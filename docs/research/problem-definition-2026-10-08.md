## 2. 데이터에서 확인한 문제 현상

### 현상 1. 반복 업무와 반복적인 AI 사용은 흔하다

- 최근 1개월 안에 반복해서 처리한 일이 있었던 사람은 24명 중 20명(83.3%)이었습니다.
- 그 일을 직접 처리하는 번거로움은 평균 4.20점(5점 만점, 20명)이었습니다.
- 같은 작업을 AI에게 여러 번 요청해본 사람은 24명 중 22명(91.7%)이었습니다.
- 반복 업무는 업무보고, 자료 조사·요약, 회의록, TIL·블로그, 데이터 정리 등이었습니다.

### 현상 2. 가장 큰 불편은 결과를 확인하고 고치는 시간이다

AI를 계속 쓰지 않게 된 이유(Q11, 중복 선택)

| 응답 | 인원 |
| --- | --- |
| 결과를 확인하고 수정하는 시간이 많이 들었다 | 12명 (50.0%) |
| 원하는 결과를 얻기 위해 매번 수정해야 했다 | 8명 (33.3%) |
| 같은 작업을 할 때마다 요청 내용을 다시 입력해야 했다 | 7명 (29.2%) |

AI를 쓰려고 할 때 막히는 점(Q10, 중복 선택)

| 응답 | 인원 |
| --- | --- |
| AI 결과를 신뢰하기 어렵다 | 10명 (41.7%) |
| 비용이 부담된다 | 9명 (37.5%) |
| 회사 자료나 개인정보를 입력하기 부담스럽다 | 7명 (29.2%) |
| 원하는 결과를 얻으려면 어떻게 질문해야 할지 모르겠다 | 6명 (25.0%) |
| 내가 하는 일 중 AI에게 맡길 만한 일이 뭔지 모르겠다 | 3명 (12.5%) |

"확인·수정 시간이 많이 들었다"고 답한 12명 중 7명은 "결과를 신뢰하기 어렵다"도 함께 골랐습니다.

### 현상 3. 같은 작업을 다시 시키는 방법은 절반 정도만 정리되어 있다

같은 작업을 다시 시킬 때의 방법(Q13, 22명)

| 응답 | 인원 |
| --- | --- |
| 같은 대화방에 이어서 했다 | 6명 |
| 따로 저장해둔 내용을 사용했다 | 6명 |
| GPTs나 프로젝트 기능에 저장했다 | 4명 |
| 매번 새로 썼다 | 3명 |
| 예전에 작성한 내용을 찾아 복사했다 | 3명 |

- 저장해두고 쓰는 사람은 10명이고, 나머지 12명은 이어 쓰거나 새로 쓰거나 찾아서 복사했습니다.
- "확인·수정 시간이 많이 들었다"고 답한 12명 중 6명은 같은 대화방에 이어 쓰거나 매번 새로 쓰고 있었습니다.

주관식 응답에서도 같은 흐름이 보였습니다.

- "블로그 양식을 정해주고 그에 맞게 초안 만들어달라고 하기"
- "팀원 내용을 매번 수동으로 복사 → 팀원들 이름 제거 후 정리해달라고 요청"
- "마구잡이로 정리해 놓은 페이지를 보고, 특정 시간마다 그 내용들을 문서로 작성해주는 일"

### 현상 4. 재료는 이미 준비되어 있는 경우가 많다

반복 업무에 필요한 내용을 준비하는 방법(Q7, 20명)

- 평소에 메모해둔 걸 모은다: 7명
- 필요한 자료가 이미 한곳에 정리되어 있다: 7명
- 그때 기억을 떠올려서 쓴다: 2명
- 메일, 메신저, 캘린더 등을 다시 찾아본다: 2명

20명 중 14명(70.0%)은 재료가 이미 모여 있었습니다. 사용자가 재료를 따로 준비해야 한다는 부담은 생각보다 작을 수 있습니다.

### 현상 5. 자동 실행과 '맡길 일 찾기'는 근거가 약하다

- 반복 업무를 정해진 시간에 자동 실행해본 사람은 9명이었습니다. 자동 실행을 하지 않은 이유는 "설정 방법을 찾아보는 것이 귀찮다"(5명)와 "굳이 자동화할 만큼 필요성을 느끼지 못했다"(5명)가 같았습니다.
- 아이디어를 보여준 뒤 "맡길 수 있는 반복 업무를 찾아주는 기능"을 가장 필요한 기능으로 고른 사람은 10명(41.7%)이었습니다. 하지만 실제로 맡길 일을 몰라서 막혔던 사람(Q10)은 3명(12.5%)이었습니다.
- 정해진 시간에 자동 실행하는 기능을 가장 필요하다고 고른 사람은 1명이었습니다.

## 3. 문제 정의

> 반복되는 일을 AI에 맡기는 사람들은 같은 일을 시킬 때마다 원하는 양식과 기준을 다시 설명하고, 결과를 확인하고 고치는 데 시간을 쓴다. 저장 기능이 있어도 절반 정도는 이어 쓰거나 매번 새로 쓰고 있다.

**아직 확인하지 못한 것**

- 확인·수정이 오래 걸리는 이유가 양식·기준 때문인지, 내용이 틀리거나 빠지기 때문인지는 이 설문으로 알 수 없습니다. 양식·기준 문제라면 이 서비스로 줄일 수 있지만, 내용 정확성 문제라면 이 서비스만으로는 해결되지 않습니다.
- 저장 기능이 있는데도 쓰지 않는 이유는 확인하지 못했습니다.

이 두 가지는 동기 채널 투표로 추가 확인할 예정입니다.

## 4. 추천 서비스 방향

### 한 줄 정의

**반복되는 일을 한 번 등록해두면, 다음부터는 재료만 넣어도 내가 원하는 양식과 기준대로 결과가 나오는 서비스**

### 흐름

1. **등록:** 사용자가 지시문을 직접 쓰지 않고, 질문에 답하면서 일을 등록한다.
   - 무슨 일인가요?
   - 보통 어떤 재료가 들어가나요?
   - 결과는 어떤 모양이어야 하나요? (양식, 길이, 말투, 빼야 할 내용)
   - 예전에 잘 나왔던 결과가 있나요? (선택)
2. **실행:** 재료를 붙여 넣으면 등록한 기준대로 결과를 만든다.
3. **고친 것 반영:** 결과를 고치면 "다음부터도 이렇게 할까요?"라고 묻고, 동의하면 등록된 기준에 추가한다.

### 범위 조정

| 기능 | 이전 | 조정 후 | 근거 |
| --- | --- | --- | --- |
| 일 등록 (질문으로 기준 채우기) | 반드시 | **반드시 (핵심)** | 요청 재입력 7명, 매번 수정 8명 |
| 지금 실행 | 반드시 | 반드시 | 반복 요청 경험 22명 |
| 고친 것 반영 | 없음 | **반드시** | 확인·수정 시간 12명 |
| 맡길 일 찾기 | 반드시 | 있으면 좋음 (예시 목록 수준) | 실제로 막힌 사람 3명 |
| 정해진 때 처리 | 반드시 | 있으면 좋음 | 이미 경험 9명, 가장 필요 1명 |

## 5. 다른 서비스와의 차별점

### 이미 있는 서비스

| 서비스 | 할 수 있는 것 | 한계 |
| --- | --- | --- |
| ChatGPT GPTs·프로젝트, Claude 프로젝트 | 지시문과 예시 파일을 저장해 같은 기준으로 답하게 함 | 사용자가 지시문을 직접 써야 함 |
| ChatGPT 예약 작업 등 | 정해진 시간에 작업 실행 | 결과를 고친 내용이 다음 실행에 자동으로 반영되지 않음 |
| 프롬프트 모음 서비스 | 남이 만든 프롬프트를 가져다 씀 | 내 양식과 기준에 맞추려면 다시 고쳐야 함 |

기능만 보면 "저장해두고 다시 쓰기"는 이미 가능합니다. 설문에서도 10명은 GPTs나 저장한 프롬프트를 쓰고 있었고, 기존 루틴 기능과의 차별점을 묻는 의견이 있었습니다. 이 서비스는 이미 저장 기능을 잘 쓰는 사람이 아니라, **저장 기능이 있어도 이어 쓰거나 매번 새로 쓰는 사람**을 대상으로 합니다.

### 차별점

**1. 설정이 아니라 일에서 시작한다**

기존 서비스는 "지시문을 작성하세요"에서 시작합니다. 이 서비스는 "무슨 일인가요, 어떤 재료가 들어가나요, 결과는 어떤 모양인가요"를 물어서 기준을 채웁니다. 사용자는 지시문을 쓰지 않아도 됩니다.

**2. 고친 것이 다음 결과에 남는다**

기존 서비스에서는 결과를 고쳐도 다음에 같은 부분을 또 고쳐야 합니다. 이 서비스는 고친 내용을 등록된 기준에 추가해, 같은 수정이 반복되지 않게 합니다.

### 차별점에 대한 근거 수준

| 차별점 | 근거 | 확인이 필요한 것 |
| --- | --- | --- |
| 일에서 시작 | 저장 기능을 쓰지 않는 사람 12명 | 지시문 작성이 어려워서 안 쓰는지는 확인하지 못함 |
| 고친 것 반영 | 확인·수정 시간 12명, 매번 수정 8명 | 고치는 내용이 양식·기준인지, 내용 정확성인지 |

두 차별점 모두 가설이며, 추가 투표와 실제 사용으로 확인해야 합니다.
