## 1. 한 줄 요약

**반복되는 일을 한 번 등록해두면, 재료만 넣어도 내 양식대로 결과가 나오고, 어떤 기준이 적용됐는지 눈으로 보고 직접 고를 수 있는 서비스**

---

## 2. 문제

> 반복되는 일을 AI에 맡기는 사람들은 같은 일을 시킬 때마다 원하는 양식과 기준을 다시 설명하고, 결과를 확인하고 고치는 데 시간을 쓴다.

### 설문 근거 (24명)

| 내용 | 인원 |
| --- | --- |
| 같은 작업을 AI에게 여러 번 요청해봄 | 22명 (91.7%) |
| 결과를 확인하고 수정하는 시간이 많이 듦 | 12명 (50.0%) |
| AI 결과를 신뢰하기 어려움 | 10명 (41.7%) |
| 원하는 결과를 얻기 위해 매번 수정함 | 8명 (33.3%) |
| 같은 요청 내용을 매번 다시 입력함 | 7명 (29.2%) |
| 같은 작업을 다시 시킬 때 저장해두지 않고 이어 쓰거나 새로 씀 | 12명 / 22명 |

## 4. 차별점

### 기존 서비스와 비교

| 비교 항목 | ChatGPT·Claude 메모리 | GPTs·Claude 프로젝트 | 이 서비스 |
| --- | --- | --- | --- |
| 시작 방식 | 그냥 대화하면 쌓임 | 지시문을 직접 작성 | **질문에 답하면 기준이 만들어짐** |
| 기준의 단위 | 대화 전체 (Claude는 프로젝트별) | 프로젝트·GPT 단위 | **일 단위** (업무보고, 회의록 등) |
| 적용된 기준이 보이는가 | 메모리 목록은 볼 수 있지만, 이번 답에 무엇이 쓰였는지는 알기 어려움 | 지시문은 보이지만 결과마다 표시되지 않음 | **결과 옆에 이번에 적용된 기준을 표시** |
| 고친 내용 반영 | AI가 알아서 저장. 정정이 반영되지 않거나 예전 내용과 섞이기도 함 | 사용자가 지시문을 다시 고쳐야 함 | **고친 뒤 "다음부터도 이렇게 할까요?" → 사용자가 확인한 것만 추가** |
| 재료 넣는 방식 | 자유 입력 | 자유 입력 | **일마다 정해둔 재료 칸에 붙여 넣기** |

### 한 문장으로

> 기존 서비스는 **AI가 알아서 기억**하거나 **사용자가 지시문을 직접 써야** 한다. 이 서비스는 **질문에 답해서 일마다 기준을 만들고, 그 기준이 결과마다 보이며, 사용자가 확인한 것만 쌓인다.**

### 왜 이 차별점이 필요한가

- **"믿기 어렵다"에 대한 답:** 설문에서 AI를 쓸 때 막히는 점 1위가 "결과를 신뢰하기 어렵다"(10명)였습니다. 어떤 기준으로 만들었는지 보이면 확인할 곳이 분명해집니다.
- **"매번 고친다"에 대한 답:** 고친 내용이 그 일의 기준으로 남아서, 같은 수정을 반복하지 않습니다.
- **"지시문 쓰기"를 건너뜀:** 저장 기능이 있어도 쓰지 않는 12명이 지시문을 쓰지 않고도 기준을 만들 수 있습니다.

### 근거 수준

| 차별점 | 근거 | 확인되지 않은 것 |
| --- | --- | --- |
| 질문으로 기준 만들기 | 저장 기능을 쓰지 않는 사람 12명 | 지시문 작성이 어려워서 안 쓰는지는 모름 |
| 적용된 기준 표시 | 신뢰 어려움 10명 | 기준이 보이면 신뢰가 올라가는지는 모름 |
| 확인한 것만 기준에 추가 | 매번 수정 8명, 기존 메모리의 정정 누락 사례 | 실제로 수정 횟수가 줄어드는지는 모름 |

세 가지 모두 가설이며, 엑스포에서 실제 사용 반응으로 확인합니다.

## 5. 다루지 않는 것

- **AI 결과의 정확성:** 틀린 내용을 바로잡는 것은 이 서비스로 해결할 수 없습니다. 공개 조사에서 수정 이유 중 정확성이 40%였고, 이 서비스는 나머지인 표현(34%), 서식(31%), 맥락 누락 쪽을 다룹니다.
- **반복 업무 찾기:** 맡길 일을 몰라서 막힌 사람은 3명(12.5%)이라 예시 목록 정도로만 둡니다.
- **정해진 때 자동 실행:** 이미 해본 사람이 9명이고, 가장 필요하다고 고른 사람은 1명이라 나중으로 미룹니다.

## 6. 사용자 흐름

예시: 매주 금요일 주간 업무보고

1. **내 일 목록:** 처음에는 예시 일(업무보고, 회의록, TIL·블로그, 자료 요약, 일정 정리)을 보여줌
2. **일 등록:** 질문에 답함
   - 무슨 일인가요?
   - 보통 어떤 재료가 들어가나요?
   - 결과는 어떤 모양이어야 하나요? (양식, 길이, 말투)
   - 예전에 잘 나왔던 결과가 있나요? (선택)
   → 답을 바탕으로 "이 일의 기준" 목록을 보여주고, 확인하면 저장
3. **실행:** 재료 칸에 이번 주 메모를 붙여 넣고 실행 → 결과와 함께 "이번에 적용된 기준" 표시
4. **고치기:** 직접 수정하거나 "더 짧게", "숫자 위주로" 같은 버튼 사용 → "다음부터도 이렇게 할까요?" → 확인하면 기준에 추가
5. **다음 주:** 같은 일을 실행하면 추가된 기준이 이미 적용되어 나옴

## 7. 기능 범위

| 구분 | 기능 |
| --- | --- |
| 반드시 | 일 등록(질문), 기준 목록 보기·수정, 실행(AI 호출), 적용된 기준 표시, 고친 것 기준에 추가, 브라우저 저장 |
| 있으면 좋음 | 예시 일 목록, 다듬기 버튼, 기준 내보내기·불러오기 |
| 나중에 | 로그인과 서버 저장, 정해진 때 자동 실행, 메일 발송, 다른 서비스 연동 |

로그인 없이 브라우저에 저장합니다. 같은 브라우저에서는 기준이 계속 쌓여 개인화가 유지되고, 엑스포 방문자가 가입 없이 바로 써볼 수 있습니다. 브라우저를 바꾸면 데이터가 사라지는 한계는 회고에 적습니다.
