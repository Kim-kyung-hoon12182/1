# 또시켰네

반복하는 문서 작업(주간보고, 회의록, 자료 요약)을 AI에게 시키고, 결과에서 확인할 곳을 표시하고, 고쳤는지 기록해서 맡겨볼 만한 때를 알려 주는 PC 웹 앱.

> 시키는 건 한 번, 반복은 그만.

- 앱 코드: [`app/`](app/) (React + Vite + Tailwind, Vercel 서버 함수, Gemini)
- 요구사항 정의서: [`docs/PRD.md`](docs/PRD.md)
- 화면·기능 정의서: [`docs/screen-spec.md`](docs/screen-spec.md)
- 배포: [`docs/deploy.md`](docs/deploy.md)
- 미해결 이슈와 결정 기록: [`docs/open-issues.md`](docs/open-issues.md)
- 테스트 결과: [`docs/test-report.md`](docs/test-report.md)
